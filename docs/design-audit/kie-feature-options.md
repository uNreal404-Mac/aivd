# 缺的功能能不能在 KIE 上接（2026-11-24 查）

价格来自 kie.ai/pricing 背后的公开价格接口和各模型产品页，参数来自 docs.kie.ai，都是 2026-11-24 读取的。积分按项目里 `config/kie-pricing.ts` 的公式换算：

- 视频：积分 = ceil((成本 × 1.95 + 0.15) / 0.01 / 5) × 5
- 图片、音频：积分 = max(2, ceil((成本 × 1.15 + 0.002) / 0.0042559))

所有接口的调用方式都和现有的 `kie.ts` 一样：先创建任务，再回调或轮询拿结果，所以接起来不用改整体架构。

## 接入时要注意

- **参考视频要计费**：一用参考视频，扣费就要先知道输入视频有多长。现在的计价函数拿不到这个数，要补上。
- **Seedance 的参考视频分辨率有限**：只收 480p 或 720p，用户传 1080p 会被拒，要先转码或在上传时拦下。
- **部分模型计费口径不清**：Kling 动作迁移、Wan 2.7 编辑、Gemini 续写只写了"按秒"，没说清楚算的是输出秒数还是输入秒数。正式接入前要先用小额测一次核实。
- **Kling 动作迁移可能少出不退**：KIE 页面写明，动作太复杂时可能出更短的片子，而且不退积分。我们这边要提前告诉用户。
- **翻译只能和英语互译**：用来翻译的语音转写模型只支持其他语言和英语之间互译，中译日这类要另找大模型来翻。
