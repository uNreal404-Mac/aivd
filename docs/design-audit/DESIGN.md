# aivd 设计规格（草稿 v0.1，2026-11-24）

> 用途：以后让 AI 改任何页面，都先让它读这份文件，**只许用这里的值**。
> 依据：[README.md](README.md) 里对 Higgsfield、Pollo 和我们自己首页的实测数据。
> 标了 **【待你拍板】** 的是需要你来定的；其余是建议值，可以直接执行。

---

## 1. 颜色

### 底色台阶（4 层，固定，不许在组件里另调）
| 变量 | 值 | 用在哪 | 现在的值 |
|---|---|---|---|
| `--du-bg` | `#0E0F12` | 页面底色 | `#050608`（太黑，台阶拉不开） |
| `--du-surface` | `#16181C` | 卡片、输入框 | `#111318` |
| `--du-surface-2` | `#1E2025` | 悬停、选中、二级面板 | `#171920` |
| `--du-surface-3` | `#272A30` | 弹层、下拉菜单 | （没有） |

描边：`--du-border: rgba(255,255,255,0.08)`；强一级 `--du-border-strong: rgba(255,255,255,0.14)`。

### 文字（白色按透明度分 4 级）
| 变量 | 值 | 用在哪 |
|---|---|---|
| `--du-text` | `#F5F5F7` | 标题、主要文字 |
| `--du-text-muted` | `rgba(245,245,247,0.72)` | 正文、说明 |
| `--du-text-dim` | `rgba(245,245,247,0.50)` | 次要信息、数据 |
| `--du-text-faint` | `rgba(245,245,247,0.32)` | 占位符、禁用 |

### 强调色（只有一个，平涂）
- `--du-accent: #1DE8F0`，悬停 `#53F3F8`，按钮上的文字 `#04070A`。**【待你拍板】** 是否保留青色。保留就要守住“只此一色”；也可以换一个更有辨识度的颜色，但不能用 Higgsfield 的黄绿或 Pollo 的橙。
- 绿、红、黄**只用于状态**：成功、错误、警告。不用来装饰。

### 禁止
- `--du-gradient`、`--du-glow`、`--du-tier-pro-glow`：删掉所有用处。
- 渐变文字（`background-clip: text`），以及“半句青色、半句白色”的双色标题。
- 组件里写 `color-mix()` 去调背景色、描边色。需要新颜色就先加进本文件。

## 2. 字体

- 正文：`Inter` + `PingFang SC` / `Noto Sans SC`（中文）。
- 展示字体：只用于首屏主标题和模型名（如 SEEDANCE 2.5、VEO 3.1）。**【待你拍板】** 继续用现在的 `fontDisplay`（Space Grotesk 系），还是换成窄体大写（例如 Oswald、Barlow Condensed）。不要和 Pollo 一样用 Bebas Neue。
- 等宽字体：只用于数字、价格、代码。**不用来做英文小标签。**

### 字号（8 档，只许用这些）
| 档位 | px | 行高 | 字重 | 用在哪 |
|---|---|---|---|---|
| 2xs | 11 | 14 | 500/600 | 只给徽章、小标签（**最小 11，正文不许小于 12**） |
| xs | 12 | 16 | 400/500 | 数据、辅助说明 |
| sm | 13 | 18 | 400/500 | 按钮、胶囊、表单 |
| base | 14 | 20 | 400/500 | 卡片说明、列表 |
| md | 16 | 24 | 400/500 | 正文（中文段落行高可放到 26） |
| lg | 20 | 28 | 600 | 卡片标题 |
| xl | 28 | 34 | 600 | 区块标题 |
| 2xl | 40 | 44 | 700 | 页面主标题 |
| 3xl | 56 | 60 | 700 | 只给首屏或营销大字 |

- 字重只用 **400 / 500 / 600 / 700**，禁止 800、900。
- 20px 以上的标题字距 `-0.02em`；正文字距保持默认。

---

## 3. 圆角（5 档）
| 变量 | 值 | 用在哪 |
|---|---|---|
| `--r-xs` | 6px | 小徽章、标签 |
| `--r-sm` | 10px | 按钮、输入框 |
| `--r-md` | 14px | 卡片、视频缩略图 |
| `--r-lg` | 20px | 大面板、输入框外框 |
| `--r-pill` | 999px | 只给胶囊按钮和筛选标签 |

---

## 4. 间距与布局

- 间距档位：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96，其他数字一律不用。
- 页面容器**只有一种**：`max-width: 1440px; padding-inline: 24px`（手机 16px）。现在混用 5 种宽度，要全部统一。
- 区块之间：桌面 64px，手机 40px。
- 卡片网格间距：12px（密集的视频墙）或 16px（普通卡片）。
- 同一行的媒体比例固定：横版 16:9，竖版 9:16，不要在一行里混排。

---

## 5. 阴影与质感（总共 3 种）
| 变量 | 值 | 用在哪 |
|---|---|---|
| `--shadow-pop` | `0 12px 32px rgba(0,0,0,0.5)` | 弹层、下拉菜单 |
| `--shadow-btn` | `inset 0 -2px 0 rgba(0,0,0,0.25)` | 主按钮（做出按下去的手感，替代发光） |
| `--shadow-hairline` | `inset 0 1px 0 rgba(255,255,255,0.06)` | 卡片顶部的细高光，可选 |

- 卡片默认**不加阴影**，层次靠底色台阶。
- 毛玻璃（`backdrop-filter`）只给顶部导航和弹层用。

---

## 6. 组件规则

### 区块头（全站统一）
```
[区块标题 28/600 单色]                       [查看全部 →]（文字链接，不是发光按钮）
[一行说明 14/400 text-dim]（可选）
```
不要英文等宽小标签，不要双色标题，不要右侧发光大按钮。

### 按钮
- 主按钮：`--du-accent` 平涂 + `--shadow-btn`，高 36（小号 32），圆角 `--r-sm`，字号 13–14/600。
- 次按钮：`--du-surface-2` 底 + `--du-border` 描边。
- 文字按钮：无底色，`--du-text-muted`，悬停变 `--du-text`。
- 一个可视区域里**只能有一个主按钮**。

### 媒体卡片
- 每个视频都要有 poster 封面图。
- 悬停：媒体放大 1.03 倍，描边变成 `--du-border-strong`，动画 160ms ease-out。不加发光。
- 卡片上的文字压在底部渐变遮罩上（黑色 0→60%），标题 14/600，数据 12/400 text-dim。

### 徽章
- 全页同时出现的徽章不超过 3 个；导航栏里最多 1 个。

## 7. 素材规则（对质感影响最大）
- 同一个素材**全页只用一次**（轮播为了循环复制的除外）。
- 首屏轮播和各区块入口用**设计过的封面**：画面上直接做大字标题，统一字体和色调。
- 同一行的素材色调要统一，挑同一种调色风格，比如都偏电影暖色，或者都偏冷色夜景。
- 视频压到 2–4 MB，配 30 KB 以内的 webp 封面。

---

## 8. 动效（已落地：styles/motion.css，测试 tests/motion-language.test.ts 把关）
- 时长 4 档：--m-instant 120ms（按下、悬停、图标切换、离开）、--m-fast 180ms（菜单/弹层出现、指示条）、--m-base 260ms（对话框、展开、内容切换）、--m-slow 380ms（区块进场、大图查看）。
- 曲线 3 条：--m-ease-out（出现、移动）、--m-ease-in-out（原地变化）、--m-ease-exit（离开）。离开比出现快。
- 挂载式弹层用 hooks/use-presence（data-state=open/closed），分段控件用 hooks/use-segment-indicator（.du-seg）。
- 只动 opacity 和 transform；不做装饰性循环；减弱动态下不动，但加载转圈照转。
- 不要持续循环的光效、跑马灯、呼吸灯。
- 遵守减弱动态设置：沿用 `reduced-motion.ts` 和 `hover-play.ts` 现有的规则。

## 9. 给 AI 的固定开场白（复制使用）

```
先读 docs/design-audit/DESIGN.md，只许用里面的颜色、字号、字重、圆角、间距、阴影。
不许新增 color-mix、渐变、发光、800/900 字重、10/11px 字号、新的 max-width。
这次只改【区块名】这一个区块。
参考：【参考站截图路径】（只学间距、层次和节奏，不学它的配色和素材）。
改完在 1440×900 和 390×844 下各截一张图，和参考图并排，
逐条列出还差在哪（具体到 px 和变量名），再改一轮，最多 3 轮。
```
