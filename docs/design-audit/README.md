代码层面（`apps/video/src/components/hf/*.css`，共 8723 行）：`--du-*` 变量体系是有的，颜色也都引用了变量。但写了 171 处 `color-mix()` 临时调色，另有 44 种不同的 `box-shadow`、32 种 `font-size`、18 种 `border-radius`、16 种 `letter-spacing`。**规范存在，但没有被强制执行**：每个组件都在自己调一点，叠起来就乱了。

## 诊断：差距在哪（按影响从大到小）

### 1. 强调色太多、到处发光：“廉价感”最大的来源
两个参考站都**只有一个强调色，而且是平涂的**：Higgsfield 的黄绿、Pollo 的橙，都不发光、不渐变。我们是青蓝渐变按钮 + 青色外发光（17 处）+ 青色渐变大面板 + 双色标题 + 绿色文字 + 黄色“预览”徽章 + 青色“送 75 积分”胶囊。
**改法：** 只留一个平涂的青色；删掉 `--du-glow` 和 `--du-gradient` 的所有用处；标题全部改成单色。

### 2. 字太重、字号太碎、行距太松
800/900 超粗体用在 540 多个字上，看起来像在“喊”；还有 10px 的字（138 个字符）。正文行高 1.7 是博客文章的节奏，不是工具产品的节奏。参考站都只用 4 种字重，最小 12px，正文行高约 1.5，大标题收紧字距（Higgsfield 是 -4%）。
**改法：** 字重只用 400/500/600/700；字号锁成 8 档；正文行高 1.5（中文段落 1.6）；大标题字距 -0.02em。

### 3. “AI 模板味”装饰
- 中文页面上每个区块都顶着英文等宽小标签：`FLAGSHIP VIDEO ENGINE`、`SHORTS & VFX STUDIO`、`INFINITE CANVAS · 无限画布`、`AI VIDEO AGENT · 创作空间`。这是 AI 生成页面最典型的特征。
- 胶片齿孔装饰条、导航里的“预览”徽章、“3 新模型”胶囊、“送 75 积分”胶囊。
- 每个区块都是同一个模板：小标签 + 双色标题 + 副标题 + 右侧发光按钮。

**改法：** 删掉所有英文小标签和齿孔条；区块头只留“标题 + 一行说明 + 右侧文字链接”；导航只保留一个徽章。

### 4. 层次靠阴影和模糊撑，不是靠底色台阶
我们的底色 `#050608` 接近纯黑，卡片只比它亮一点点，所以只能靠描边、阴影、毛玻璃去区分层次，结果出来 38 种背景色、41 个模糊元素。Higgsfield 的做法是底色 `#0F1113`、卡片 `#1C1E21`、悬停 `#23262A`，台阶清楚，几乎不靠阴影。
**改法：** 固定 4 层底色（见 DESIGN.md），禁止组件里自己写 `color-mix()` 调背景，毛玻璃只留给导航栏和弹层。

### 5. 素材重复，缺少“主视觉”
同一批素材在不同区块里反复出现。按页面源码统计：红毯图 `red-carpet` 出现 6 次，“男孩和狗”“雨夜情侣”各 5 次，“秋日散步”“舞者”“梦境”各 4 次，龙的视频用了 3 次（轮播为了循环复制的幻灯片也算在内）。素材一重复，页面就显得“小”、像模板。参考站的推广卡片是**设计过的封面**，标题直接做在画面里（Higgsfield 的 “MAGI-2 IS LIVE”“GPU”，Pollo 的 “GTA6 VIDEO”“POLLO RELIGHT”），不是把生成结果直接贴上去。
**改法：** 同一个素材全页只用一次；给首屏轮播和各区块入口做 6–8 张带大字标题的封面图；同一行素材统一色调。

### 6. 对不齐：5 种容器宽度
1080、1120、1360、1480、1680 五种最大宽度混用，各区块左右边缘对不齐。参考站全页只用一种容器宽度。
**改法：** 统一成一种容器：最大 1440px，左右内边距 24px（手机 16px）。

### 7. 首屏塞得太满
口号 + 列了 4 个模型名的副标题 + 3 个标签 + 输入框 + 6 个灵感词 + 7 个功能入口 + 一行信任说明，首屏共 45 个可点元素。Pollo 首屏结构和我们几乎一样（问句 + 标签 + 输入框 + 一行功能入口 + 轮播），但标题是 24px 的细体，副标题、第二排入口、信任说明都没有。
**改法：** 主标题缩小、减重；删掉副标题里的模型列表；功能入口和灵感词合成一排；信任说明挪到输入框下面的小字或者删掉。

### 附带发现（小）
- `/home/hero-showcase-02.mp4` 这个视频没有封面图（poster），慢网速下会先显示黑块。
- 第一次打开时，首屏下方三张大卡片 9 秒时还是空的；第二次 3 秒就出来了，复现不了，可能是冷缓存加轮播切换撞在一起。先记下，不算确定的问题。

## 下一步怎么用这份报告

1. 先定 [DESIGN.md](DESIGN.md) 里标了“待你拍板”的几项，比如是否保留青色、展示字体用哪个。
2. 先把 `theme.css` 的 token 按 DESIGN.md 收紧，这一步全站一起变。
3. 再**一次只改一个区块**，改完用 `node docs/design-audit/measure.mjs` 重测并截图，和参考站并排对比，最多 3 轮。
4. 给 AI 的指令用 DESIGN.md 末尾的固定开场白，不要再写“旗舰级”“2026 标准”这类形容词。

声明：这里学的是参考站的**设计方法和数值节奏**，不照搬它们的配色（黄绿/橙）、字体组合、素材和品牌元素。
