# Motion sources

The two opposite rows apply the repeat-and-reverse pattern from [Aceternity Infinite Moving Cards](https://ui.aceternity.com/components/infinite-moving-cards) and the local `components/ui/marquee.tsx`. This implementation moves a native scroll area so keyboard navigation, direction buttons and the mobile touch layout still work. The timeline, film cues and billing transition are written for this site. All use existing site colour tokens, CSS, SVG or the installed Motion dependency.
