# Motion sources

The single-surface model spotlight adapts the pointer offsets and radial fill from the TypeScript/Tailwind version of [React Bits SpotlightCard at c83b5e7](https://github.com/DavidHDev/react-bits/blob/c83b5e7e026f003af33ff9ebc3d93afb5c86ad22/src/ts-tailwind/Components/SpotlightCard/SpotlightCard.tsx). The footer action adapts the opposite moving highlights from the same version of [React Bits StarBorder](https://github.com/DavidHDev/react-bits/blob/c83b5e7e026f003af33ff9ebc3d93afb5c86ad22/src/ts-tailwind/Animations/StarBorder/StarBorder.tsx). The original copyright and MIT + Commons Clause terms are included in [LICENSE.react-bits.md](./LICENSE.react-bits.md).

The two opposite rows apply the repeat-and-reverse pattern from [Aceternity Infinite Moving Cards](https://ui.aceternity.com/components/infinite-moving-cards) and the local `components/ui/marquee.tsx`. This implementation moves a native scroll area so keyboard navigation, direction buttons and the mobile touch layout still work. The hero light, timeline, beam paths and billing transition are drawn for this site. All use existing site colour tokens, CSS, SVG or the installed Motion dependency.
