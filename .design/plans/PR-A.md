# PR-A 本地草稿 · 已选 A · 宽银幕首映

基线为 Premiere；本轮唯一 section 为首页首屏生成器。两个参考图分别为 [.design/refs 中的影片层级](../refs/film-hierarchy.png) 和 [生成控件](../refs/generator-controls.png)。前者只学影像的视觉主次，后者只学「模式 → 参数 → 主动作」的排列。

**Visual thesis**　用黑色画框和清晰的分镜输入台保留 Premiere 的展映气质，让电影内容承担色彩，用青色标记当前模式和生成动作。
**Content plan**　保留原 H1 的两个子节点。仅将 H1 之外的 intro 改成基于真实配置的权益说明。生成器给出文生/图生、可用模型、画幅/时长/分辨率与当次积分；框下放六个可直接填入的示例。
**Interaction thesis**　切换模式后只保留兼容模型/设置，改参数后同步读已有权威积分计算；点示例填入但不提交；「用这段分镜」「从图片开始」为 ghost。提交把草稿交给现有工作台，在既有流程内确认生成。

1. 看第一帧，辨认片名和当前工具。
2. 选模式，写镜头或从六个示例开始。
3. 选模型、比例、时长、分辨率，同时看到对应积分。
4. 以唯一主动作进入正确的工作台，核对带入的 prompt 和 model。

**两套静态方案**　A 为宽银幕 + 片下编辑器；B 为桌面侧置编辑器 + 手机紧凑画面。两套均已生成 375、390、1440 的实际 PNG 和自包含 HTML，保存在工作区 outputs/ui-af-foundation/pr-a/options。用户已选 A，保留宽银幕海岸，在影片下方实现编辑器。模型和积分值必须来自原配置，源中真实默认能力不等同于外部厂商最新发布。首页公告/导航暂按 Premiere 基线保留，外部主样式候选记录给 PR-D；PR-A 不跨 section 修改。
